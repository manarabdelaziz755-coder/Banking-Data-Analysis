# 🏦 Banking Data Analysis

## 📌 Project Overview

This project analyzes banking customer and transaction data to uncover valuable business insights using SQL, Python, and Power BI.

---

## 🛠️ Tools Used

- SQL Server
- Python (Pandas, Matplotlib, Seaborn)
- Power BI

---

## 📂 Dataset

The project uses a synthetic banking dataset containing:

- Customer Data
- Transaction Data
- Bank Branch Data

---

## 📊 Project Workflow

1. Data Cleaning
2. Data Exploration
3. SQL Analysis
4. Python Analysis
5. Power BI Dashboard
6. Business Insights

---

## 📈 Dashboard Pages

- Overview Dashboard
- Customer Analysis
- Transaction Analysis
- Bank Performance

---

## 📌 Key Insights

- Top customers by transaction amount
- Investment distribution
- Transaction trends
- Customer demographics
- Revenue and profit analysis
